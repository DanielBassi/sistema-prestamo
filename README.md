# Sistema de Gestión de Préstamos Bancarios

El README.md del BACK-END como el FRONT-END estan dentro de cada carpeta correspondiente.

Proyecto desarrollado como prueba técnica FullStack Java + React.

## Descripción

La aplicación permite gestionar solicitudes de préstamos bancarios. Los usuarios pueden solicitar préstamos y consultar su estado, mientras que los administradores pueden aprobar o rechazar solicitudes.

## Tecnologías principales

### Backend
- Java 17
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- H2
- JUnit 5
- Mockito
- Caché

### Frontend
- React
- TypeScript
- Vite
- Axios
- React Router
- React Hook Form
- Zod
- Tailwind CSS
